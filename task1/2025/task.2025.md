# Задание №1

## Что требуется:

### Что было сделано на первом семинаре:

1. Установить PostgreSQL 16 / 17 (варианты на ОС / docker).
2. Создать базу данных с настройками Lang = ru_RU.UTF-8, аутентификация scram-sha-256 (по умолчанию).
3. Создать пользователя с доступом USAGE к этой БД и схеме public в ней.
4. Разработать приложение на любимом языке программирования, удовлетворяющее следующим требованиям:
   1. Подключаться к БД и выполнять SQL-запрос:

      ```sql
      SELECT VERSION();
      ```

### Что требуется доделать:

Разработанное приложение должно:

1. Считывать настройки подключения к БД, лежащие рядом в файле, например `*.conf` или `*.json`, `*.yaml`, `*.toml`.
2. Получать от пользователя логин и пароль для подключения к БД, консоль / графический интерфейс.
3. Каким-либо образом безопасно соединять данные из файла и полученные от пользователя, таким образом, чтобы пользователь своим вводом не мог добавить своих опций в параметры подключения к БД.

## Требования для сдачи приложения:

1. Расположить исходный код программы + `postgresql.conf` / `Dockerfile` в любом из публичных git-репозиториев (GitHub, GitLab, Gitea, Bitbucket, …).
2. Продемонстрировать работу приложения.
3. Ответить на вопросы преподавателя.
