# Задание №4

1. Для приложения, разработанного в рамках задания №3, разработать диаграмму потоков данных, используя Microsoft Threat Modeling Tool, или OWASP Threat Dragon, или другое аналогичное приложение с применением методологии STRIDE.
2. Если используемое приложение сгенерировало для вас угрозы на основе диаграммы из пункта 1, то их необходимо локализовать.
3. Провести оценку рисков каждой угрозы согласно методике DREAD, оценочные значения критериев для каждой угрозы представить в виде таблицы.
4. Оформить результаты в виде диаграммы, таблиц расчёта рисков и финальной таблицы угроз с общей оценкой риска, отсортированной по убыванию.
5. Для пяти самых критичных угроз найти соответствующие угрозы в [банке данных угроз безопасности информации ФСТЭК России](https://bdu.fstec.ru/threat).

## Требования для сдачи:

1. Представить исходные файлы модели — диаграммы.
2. Представить файл-отчёт с диаграммой потоков данных, списком локализованных угроз по методологии STRIDE, таблицами оценки DREAD и итоговой таблицей угроз, с таблицей или списком из 5 самых критичных угроз и их соответствием угрозам безопасности информации согласно банку данных угроз безопасности информации ФСТЭК России.
3. Ответить на вопросы преподавателя.
