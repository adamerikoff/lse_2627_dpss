# Задание №5

1. Для приложения, разработанного в рамках задания №3, и на основе таблицы угроз из задания №4 составить «чек-лист обеспечения безопасности приложения» (чек-лист).
2. При составлении формулировок «чек-листа» ориентироваться на пункты из стандартов OWASP Application Security Verification Standard, CWE, CVE или любые другие подходящие стандарты (ГОСТы, приказы ФСТЭКа или др.), или самостоятельно сформулировать.
3. Пункты «чек-листа» должны формулироваться в позитивном ключе, например «в приложении должно обеспечиваться ...», «приложение должно обеспечивать ...», «реализация приложения должна соответствовать ...».
4. В чек-лист обеспечения безопасности приложения должны входить только пункты, действительно подходящие приложению из практики №3 и соответствующие угрозам, имеющим наибольший риск, из таблицы угроз задания №4.
5. Оформить «чек-лист» в виде таблицы, в отдельной колонке которой будут ссылки на строки модели угроз, а в следующей колонке — ссылки на пункты из стандартов обеспечения безопасности (OWASP ASVS, CWE, CVE, ГОСТы, приказы ФСТЭКа), которым соответствует пункт чек-листа. Для каждого пункта чек-листа достаточно использовать одну ссылку на стандарт безопасности, если он применим.

## Требования для сдачи:

1. Таблицу, содержащую «чек-лист обеспечения безопасности приложения», с перекрёстными ссылками на стандарты безопасности и таблицу угроз.
2. Ответить на вопросы преподавателя.
