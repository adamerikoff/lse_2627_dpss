# Задание №7

1. На основе приложения, разработанного в практическом задании 3, разработать программу с веб-интерфейсом:
   1. На первой странице (страница входа) пользователю необходимо ввести все значения, необходимые для работы с БД (логин и пароль), и нажать кнопку «Войти»; по нажатию на которую, если введены правильные данные, происходит переход на следующую страницу.
   2. На следующей странице (главная страница) расположены кнопки (или ссылки) — переходы на отдельные страницы с полезными для пользователя функциями.

      По желанию можно совместить главную страницу и страницу входа, тогда перед переходом на другие страницы необходимо проверять правильность ввода данных пользователя.

   3. Страница просмотра таблиц БД.

      По желанию можно эту страницу разбить на отдельные страницы (по таблицам / по фильтрам).

   4. Страница для добавления новых строк в таблицы БД.

      По желанию можно эту страницу разбить на отдельные страницы (по таблицам / по добавлению в одну таблицу или несколько таблиц).

   5. Страница для обновления данных в существующих записях строк БД.

      По желанию можно эту страницу разбить на отдельные страницы (по таблицам / обновление одной записи или обновление нескольких записей).

   6. Неудачные попытки входа в приложение должны логироваться.
   7. Написать Dockerfile, который упаковывает скомпилированное / интерпретируемое приложение и все необходимые для его работы зависимости, в том числе файл конфига.
   8. Добавить в Dockerfile команду для автозапуска приложения при старте контейнера.
   9. Собрать тегированный образ Docker на основе файла Dockerfile.
   10. Подключить собранный образ в Docker Compose с PostgreSQL Docker-образом.
   11. При реализации программы обеспечить безопасную передачу в запросы параметров. Особенно обратить внимание на безопасность передачи в запрос группы однотипных значений.

## Требования для сдачи:

1. Расположить SQL-скрипты, код для заполнения БД, исходный код программы, Dockerfile, Env-файл, Docker Compose-файл в отдельный публичный репозиторий или в отдельную ветку предыдущего репозитория.
2. Продемонстрировать работу приложения, пункты 1.1–1.5.
3. Ответить на вопросы преподавателя.
