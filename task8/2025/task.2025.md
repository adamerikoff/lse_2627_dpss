# Задание №8

1. Установить одно отдельное (standalone или VS Code) универсальное SAST-средство по выбору, например CodeQL VS Code (https://marketplace.visualstudio.com/items?itemName=github.vscode-codeql), codeql-cli (https://github.com/github/codeql-cli-binaries/releases), SonarQube, semgrep или любое другое.
2. Установить специализированное для вашего языка программирования средство, например dotnet tool security-scan (security-code-scan) (C# .NET), securego/gosec (Go), Staticcheck (Go) или любое другое подходящее.
3. Разместить в различные папки исходный код приложения из задания 3 и задания 7.
4. Настроить оба SAST-средства для проверки исходного кода обоих приложений.
5. Оформить результаты каждого SAST-средства для каждого приложения в виде отдельной таблицы, с колонками: файл, строка, тип ошибки, подробности.
6. Свести результаты обоих средств по каждому приложению в сводную таблицу, отсортировав строки от тех проблем в коде, которые требуется исправить в первую очередь, до несущественных; в конце таблицы разместить ложные срабатывания.
7. Добавить в сводную таблицу столбец с соответствующим приоритетом исправления или указанием на ложное срабатывание.
8. Сделать вывод об увеличении / неизменности количества ошибок / ложных срабатываний при усложнении приложения от задания 3 до задания 7.

## Требования для сдачи:

1. Продемонстрировать исходные файлы отчётов SAST-средств для каждого приложения.
2. Отчёт с 6 таблицами: по каждому из 2 приложений по 2 таблицы SAST и одной сводной таблице. В отчёте должен присутствовать вывод.
3. Ответить на вопросы преподавателя.
